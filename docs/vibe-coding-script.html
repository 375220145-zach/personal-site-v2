拍摄原因

什么是 vibe coding

Vibe coding 是一种"许愿式编程"——用户不懂编程，通过自然语言描述意图，AI 全权负责实现。用户只关心结果对不对，不关心技术过程。常见模式：让 AI 自己做决策、改需求时要求不破坏已有部分、只验收不追问。

这个短片的笑点

A 在认真规划旅行，B 把 vibe coding 的思维模式无意识代入日常对话——B 不是故意不帮忙，是已经习惯了"许愿式交流"。懂 vibe coding 的人会心一笑，不懂的也会觉得"这个朋友怎么这么离谱"。

前期准备

道具

  • 样板手机（卡纸制作即可）
  • 手绘苹果标签：白纸+马克笔画苹果，胶带贴在屏幕背面
  • 电脑 + 显示器（真实或道具均可）

场景

  • A 区域：自然光，居家/沙发背景。无额外道具
  • B 区域：电脑桌，屏幕朝向镜头
  • 两个区域的视线方向要能对上

角色 & 声音

出镜

A 和 B 均由 Mira 一人分饰，全部通过后期对切完成。先拍完 A 的所有镜头，换造型/位置后再拍 B。

声音后期

A 女声 = Mira 原声（或变调处理成女声）
B 男声 = Mira 压低配男声 / 录音后降调

拍摄顺序

组一 · A 机位

居家场景。A1–A8 按顺序拍。每段台词之间留 2–3 秒静默余量，方便后期对切。

组二 · B 机位

电脑桌场景。B1–B7 按顺序拍。B1–B4 全程不抬头看镜头方向；B5 第一次抬头；B6 对视。
